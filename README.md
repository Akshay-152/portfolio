## Featured Projects

These projects are drawn from my public GitHub repositories and project work. The descriptions reflect the repository documentation and the features implemented or documented there. Some projects are ongoing or evolving.

### 1. Smart Exam Seating Management System

**Repository:** [smart-exam-seating](https://github.com/Akshay-152/smart-exam-seating) · [RoomAllocationApplication](https://github.com/Akshay-152/RoomAllocationApplication)

A web-based system designed to simplify examination administration and automate student seat allocation.

**Key features**
- Student, room, course/batch, and examination management
- Student, room, and exam-data imports from Excel, CSV, and PDF
- Seating allocation across branch and batch groups
- Conflict detection for overlapping exams and duplicate room/student bookings
- PDF seating-chart generation and export
- Role-based administrator and student portals
- Semester-aware exam eligibility and student views in the extended version
- Responsive interface tested across desktop, tablet, and mobile viewport sizes
- Student notifications, including real-time updates and native Web Push integration in the extended implementation

**Technology:** Java, Spring Boot, Spring Data JPA, Spring Security, MySQL, Maven, HTML, CSS, JavaScript, Apache POI, Apache PDFBox, Docker Compose, Web Push.

### 2. MUSIX — Android Music Player

**Repository:** [musicx](https://github.com/Akshay-152/musicx) · [Web preview](https://musicx-play.blogspot.com/)

A modern offline-first Android music player focused on a clean interface and a complete local music-listening experience.

**Key features documented in the project**
- Automatic scanning and organization of local music
- Song, artist, and album browsing
- Favorites, downloads, and custom playlists
- Queue management and playback controls
- Background playback and mini-player experience
- Animated vinyl-style player interface and audio visualizer
- Sleep timer and user music statistics
- Firebase-backed Sync Studio foundation for user status and music sharing
- AI Mix and recommendation-oriented interface

**Technology:** Kotlin, Android SDK, Jetpack components, Media3/ExoPlayer, Firebase Authentication, Firestore, Realtime Database, Firebase Storage, MVVM, Repository Pattern.

- Message editing, deletion, reactions, and replies

- Fullscreen image viewing with zoom and pan

**Technology:** HTML, CSS, Vanilla JavaScript, Firebase Firestore, Cloudinary.

### 5. Self-Hosted Web Push Notification System

**Repository:** [push-notification-server](https://github.com/Akshay-152/push-notification-server) · Also included in [RoomAllocationApplication](https://github.com/Akshay-152/RoomAllocationApplication)

A self-hosted notification platform using the browser's native Web Push protocol rather than depending on Firebase or a third-party notification SaaS.

**Key features**
- Browser subscription and opt-in flow
- VAPID-based push delivery
- Admin dashboard for composing and scheduling notifications
- Subscriber management and notification history
- Retry handling and delivery tracking
- SQLite-backed persistence for scheduled campaigns
- Session security, CSRF protection, rate limiting, and audit logging
- Automated tests using Node's test runner

**Technology:** Node.js, Express, SQLite, Web Push, VAPID, JavaScript, Service Workers, PWA.

### 7. PeerBeat — Server Heartbeat & Monitoring

**Repository:** [peerbeat](https://github.com/Akshay-152/peerbeat)

A reusable heartbeat service intended to monitor communication and availability between two application servers.

**Key features**
- Asynchronous heartbeat communication between peer servers
- Bearer-token authentication
- Peer health and latency tracking
- Retry and exponential-backoff behaviour
- FastAPI service with a Flask-based monitoring dashboard
- Docker and Docker Compose support
- Render deployment configuration

**Technology:** Python, FastAPI, Flask, HTTPX, Docker, Docker Compose, Uvicorn.
